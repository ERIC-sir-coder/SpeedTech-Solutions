# SpeedTech Solutions

A modern React and Vite website for **SpeedTech Solutions**, an internet service provider offering reliable internet connection, installation, and coverage services in **Kiambu South B**.

## About

SpeedTech Solutions helps homes and businesses get connected with reliable internet solutions.

The website provides information about:

- Internet connection services
- Internet installation
- Internet packages and speeds
- Coverage availability
- Customer contact and WhatsApp communication

## Technology

- React
- Vite
- JavaScript
- CSS
- Express.js
- Node.js
- ESLint
